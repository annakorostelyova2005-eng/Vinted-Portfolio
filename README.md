# Project Portfolio

This archive contains five small projects prepared as examples of my work with Python, SQL, data analysis, and machine learning.

## Projects

### 1. SQL Chemicals Project
A SQL/data analysis project focused on working with chemical-related data. The project demonstrates querying, filtering, joining, aggregating, and analysing structured data.

### 2. Python Tornados App
A Python project for analysing tornado data and building an application/model around tornado-related patterns. Large dataset/model files may be excluded from the upload version to satisfy file-size limits.

### 3. Python TRM Project
A Python machine learning research project exploring model behaviour and performance using TRM-related experiments, training scripts, and result analysis.

### 4. Scikit-learn_Pyhton-PCA
A Python project that turns AG News headlines into numerical embeddings and uses principal component analysis (PCA) and K-means clustering to explore how news categories group together. It also trains and tunes a random forest to predict whether a headline belongs to the world news category. See `PCA.ipynb`.

### 5. Scikit-learn_Pyhton-classification_on_vehicle_inspection_data
A Python project that uses vehicle characteristics to predict whether a passenger vehicle will pass its technical inspection. The project demonstrates exploratory data analysis, feature engineering, and model comparison using logistic regression and random forests. It also tests how changing the decision threshold affects precision, recall, and false passes. See `classification_on_vehicle_inspection_data.ipynb`.
