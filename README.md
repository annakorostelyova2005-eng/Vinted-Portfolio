# Project Portfolio

This archive contains three small projects prepared as examples of my work with Python, SQL, data analysis, and machine learning.

## Projects

### 1. SQL Chemicals Project
A SQL/data analysis project focused on working with chemical-related data. The project demonstrates querying, filtering, joining, aggregating, and analysing structured data.

### 2. Python Tornados App
A Python project for analysing tornado data and building an application/model around tornado-related patterns. Large dataset/model files may be excluded from the upload version to satisfy file-size limits.

### 3. Python TRM Project
A Python machine learning research project exploring model behaviour and performance using TRM-related experiments, training scripts, and result analysis.
